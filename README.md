# NEWS EDIT — Газетный редактор

Веб-сервис для создания макетов газет и журналов: вёрстка полос, работа с текстом и изображениями, сохранение проектов и экспорт в файл.

---

## Регистрация и вход

- **Регистрация** — создание аккаунта по имени (логину), email и паролю
- **Согласие с политикой** — при регистрации нужно подтвердить ознакомление с политикой обработки персональных данных
- **Вход** — авторизация по email и паролю
- **Сброс пароля** — восстановление доступа по логину и email (доступно на странице входа и в настройках)
- **Выход** — завершение сеанса из главного меню или настроек

---

## Главное меню

После входа открывается панель управления с разделами:

| Раздел | Что делает |
|--------|------------|
| **Создать файл** | Создание нового проекта |
| **Библиотека** | Все ваши сохранённые проекты |
| **Шаблоны** | Готовые макеты для быстрого старта |
| **Избранное** | Проекты, отмеченные звёздочкой |
| **Корзина** | Удалённые проекты (можно восстановить или удалить навсегда) |
| **Настройки** | Профиль, внешний вид, параметры редактора |
| **Выйти** | Выход из аккаунта |

### Работа с проектами

- Просмотр проектов в виде карточек с превью
- Открытие проекта в редакторе по клику
- Добавление в **избранное** (звёздочка на карточке)
- Перенос в **корзину** (удаление с возможностью восстановления)
- **Перетаскивание** карточки проекта на пункты «Избранное» или «Корзина» в боковом меню
- Окончательное удаление из корзины

## Создание нового проекта

При нажатии «Создать файл» можно выбрать:

### Формат полосы

- **A3** (стандартный и высокое разрешение)
- **Таблоид (US)** — американский формат 11×17 дюймов
- **Berliner** — европейский таблоид
- **A2** — увеличенный формат

Для каждого формата можно переключить **книжную** и **альбомную** ориентацию.

### Шаблон макета

- **Пустой** — чистый холст
- **Городские вести** — фото слева, три колонки текста
- **Деловой вестник** — фото справа, две колонки
- **Воскресный выпуск** — панорамное фото сверху, четыре колонки
- **Сохранённые пресеты** — ваши ранее сохранённые макеты

- Просмотр своих сохранённых пресетов
- Быстрое создание проекта на основе выбранного шаблона

## Редактор макетов

Основной экран для работы над полосой.

### Добавление элементов

- **Заголовок** — крупный текст для главного заголовка
- **Подзаголовок** — средний текст
- **Основной текст** — текстовый блок для статьи
- **Прямоугольник, круг, треугольник** — графические фигуры
- **Изображение** — загрузка картинки с компьютера

### Работа с текстом

- Выбор шрифта
- Размер текста
- Выравнивание (влево, по центру, вправо)
- Редактирование текста прямо на холсте

### Работа с объектами

- Перемещение, масштабирование, поворот
- Изменение цвета заливки (палитра и произвольный цвет)
- Настройка прозрачности
- Удаление выбранного объекта
- **Магнитные направляющие** — объекты «прилипают» к центру страницы и полям при перемещении

### Слои

- Список всех элементов на полосе
- Скрытие и показ слоя
- Переименование слоя
- Изменение порядка слоёв (что сверху, что снизу)
- Удаление слоя

### Сетка и направляющие

- **Сетка колонок** — наложение сетки 4×5 для газетной вёрстки (не попадает в экспорт)
- **Направляющие по центру** — линии для выравнивания
- **Линейки** — ориентиры по краям рабочей области
- **Привязка к сетке** — шаг 20 px при перемещении (включается в настройках)

### Шаблоны в редакторе

- Боковая панель с готовыми макетами
- Применение шаблона к текущему холсту
- Использование сохранённых пресетов

### Масштаб и навигация

- Увеличение и уменьшение масштаба
- Вписать полосу в экран одной кнопкой
- Прокрутка холста (Shift + средняя кнопка мыши)
- Масштаб колёсиком мыши с зажатым Alt

### Отмена действий

- Отмена последнего действия
- Повтор отменённого действия
- До 20 шагов истории

### Сохранение

- **Ручное сохранение** — кнопка «Сохранить» в шапке
- **Автосохранение** — периодическое сохранение (включается в настройках, интервал 30 / 60 / 120 сек)
- Сохраняется название проекта, макет и превью

### Создание пресета

- Сохранение текущего макета как шаблона для будущих проектов
- Пресет появляется в разделе «Шаблоны» и в панели шаблонов редактора

### Прочее в редакторе

- Редактирование названия проекта в шапке
- Очистка всего холста (с подтверждением)
- Переключение светлой и тёмной темы
- Переход к экспорту
- Возврат на главную с автоматическим сохранением

## Экспорт

Страница сохранения готового макета в файл.

### Форматы

| Формат | Назначение |
|--------|------------|
| **PDF** | Печать и передача в типографию |
| **PNG** | Изображение с прозрачным фоном |
| **JPEG** | Изображение для веба и соцсетей |
| **SVG** | Векторный формат |

### Параметры

- **Имя файла** — можно изменить перед скачиванием
- **DPI** — 72 (веб) или 300 (печать)
- **Цветовое пространство CMYK** — для PDF (подготовка к печати)
- **Вылеты** — дополнительное поле за края полосы для обрезки после печати
- **Метки обрезки** — угловые метки в PDF для типографии
- **Встраивание шрифтов** — шрифты включаются в PDF-файл

### Интерфейс экспорта

- Превью макета перед экспортом
- Редактирование названия файла
- Индикатор процесса генерации
- Возврат в редактор или на главную

## Настройки

### Профиль

- Просмотр имени и email
- Смена пароля

### Внешний вид

- **Светлая** и **тёмная** тема
- **Масштаб интерфейса** — 100 %, 110 % или 125 %

### Редактор

- Включение и отключение автосохранения
- Интервал автосохранения (30 / 60 / 120 секунд)
- Привязка объектов к сетке
- Показ направляющих по центру
- Показ линеек

### Экспорт по умолчанию

- Формат файла по умолчанию
- Качество экспорта
- Встраивание шрифтов в PDF

### Хранилище

- Статистика: сколько места занимают проекты и файлы
- Очистка корзины (удаление всех проектов из корзины навсегда)
- Очистка устаревших превью

### Безопасность

- Выход из аккаунта на этом устройстве

### Опасная зона

- Удаление всех проектов
- Удаление аккаунта на этом устройстве
